# Инструкции для бэкенда

Эти правила применяются к `apps/am-back` и его подкаталогам и дополняют [общие инструкции проекта](../../AGENTS.md). Перед каждой задачей в этой части проекта перечитывай этот файл.

## Подготовка

- Бэкенд — NestJS с TypeORM и PostgreSQL в общем Nx workspace. Команды ниже выполняются из корня репозитория.
- Перед изменениями изучи соответствующие контроллеры, DTO, сервисы, сущности и существующие тесты.

## Авторизация и роли

- Закрытые ручки помечай `@Auth()` на методе или контроллере. Административный доступ дополнительно ограничивай через `@Roles(UserRole.ADMIN)`.
- Используй пользователя из `RequestModel.user`, установленного `UserMiddleware` после проверки токена. Проверки авторизации и ролей выполняют глобальные `AuthGuard` и `RolesGuard`.
- Проверки существования ресурса, его состояния и принадлежности пользователю или заказу размещай в соответствующем сервисе. При скачивании проверяй принадлежность запрошенного файла разрешённому ресурсу.

## Работа с кодом

- Следуй существующему разделению: HTTP-контроллеры и DTO находятся в `src/modules`, работа с данными и соответствующая логика — в `src/db/services`.
- При изменении запросов учитывай необходимые связи, пагинацию и возможность отсутствующих или удалённых связанных сущностей.

## Контракты API и база данных

- Swagger-схема доступна в dev-режиме по адресу `http://localhost:3000/swagger/schema`. Фронтенд генерирует клиент из этой схемы командой `npm run am:front:generate:api`.
- Изменения структуры базы данных оформляй миграциями в `apps/am-back/database/migrations`, придерживаясь существующего подхода проекта.

## Команды и проверка

| Задача | Команда из корня репозитория |
| --- | --- |
| Запуск бэкенда в dev-режиме с HMR | `npm run am:back:start:dev` |
| Сборка | `npm run am:back:build` |
| Линтер | `npx nx run am-back:lint` |
| Тесты | `npx nx run am-back:test` |
| Запуск конкретного тестового файла | `npx nx run am-back:test --runInBand --runTestsByPath apps/am-back/src/path/to/file.spec.ts` |
| Генерация миграции | `npm run am:back:typeorm:migration:generate` |
| Применение миграций | `npm run am:back:typeorm:migration:run` |
