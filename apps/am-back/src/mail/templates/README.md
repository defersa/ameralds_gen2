# Шаблоны писем

Каждый шаблон — чистая функция, которая принимает данные письма и возвращает `MailTemplate`: тему, HTML и текстовую версию. Данные из БД и вложения готовятся в сервисе отправки.

- `layout.template.ts` — общая оболочка, логотип, адаптивные стили и подвал.
- `completed-order.template.ts` — оформленный заказ с карточками схем, выбранными размерами, подбором и итогом.
- `mail-template.ts` — контракт шаблонов, экранирование HTML и форматирование цен.

Верстка использует таблицы и встроенные стили. Динамический текст нужно пропускать через `escapeHtml`.

Изображения подключаются через CID-вложения из `../mail-assets.ts`. Логотип берётся из `apps/am-front/src/public/assets/amstore logo.svg`, копируется сборкой в `mail/assets` и преобразуется в PNG. Превью схем преобразуются в JPEG из публичной папки uploads; при отсутствии файла карточка показывает текстовую заглушку. Приватные файлы схем не прикладываются.

Текущая отправка `AdminOrderMailService` работает через Mailpit только при `NODE_ENV=dev`.

Для локального просмотра выполните `npm run am:mail:preview`. Необязательный аргумент — путь к превью схемы внутри uploads: `npm run am:mail:preview -- uploads/public/images/preview/example.webp`. Команда создаёт HTML, текстовую версию и `.eml` в `/tmp/amstore-order-email`, без отправки письма.
